\# Grayscale Image Converter

## 🚀 Live Website

[![Live Website](https://img.shields.io/badge/Live%20Website-Open%20Project-success?style=for-the-badge)](https://grayscale-image-converter-1.onrender.com)


\## Project Description



This project is a web-based Grayscale Image Converter developed using Python, Flask, HTML and Pillow.



The user can upload an image and the application displays:



\- Original Image

\- Grayscale Image



\## Technologies Used



\- Python

\- Flask

\- Pillow

\- HTML

\- CSS



\## Features



1\. Upload an image

2\. Display original image

3\. Convert image to grayscale

4\. Display grayscale image



\## How to Run



Install required packages:



pip install flask pillow



Run the application:



python app.py



Open the following URL in a browser:



http://127.0.0.1:5000
